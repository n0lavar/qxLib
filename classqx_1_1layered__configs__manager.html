std::expected< void, layered_configs_manager::set_error > qx::layered_configs_manager::set_string ( string_view  svRuntimeName,
string_view  svValue 
)
inlinenoexcept

Set a variable from text using its existing registered parser.

Every registered variable is writable. Conversion rules match environment and command-line parsing. On success this uses the same runtime storage as set<T>(); no file is written. Failure leaves the previous value unchanged. Call only on the manager's owning thread.

Parameters
svRuntimeName- registered runtime name, matched exactly
svValue- text to convert to the variable's declared type
Returns
- success, or unknown_variable / invalid_value error
