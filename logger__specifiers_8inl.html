template<class char_t , class traits_t >
compile_pattern_result qx::compile_pattern ( basic_string< char_t, traits_t > &  sPattern)
noexcept

Compile an fmt pattern with named arguments into replacement fields.

This function is required because std format doesn't support named arguments. This function doesn't allocate.

Template Parameters
char_t- char type (char, wchar_t, etc)
traits_t- char traits.
See also
string_traits.h
Parameters
sPattern- fmt pattern that must have only arguments from logger_specifiers. One type may be absent or present multiple times. You can use any format specifiers. The result will be in the same string.
Return values
-Compilation result. If != ok, sPattern is considered invalid.
