inline

Register an assertion interceptor.

Interceptors are tried in registration order before normal assertion handling. A matching interceptor suppresses logging, the callback and debug break. Fatal assertions still call onExit. It must not modify the interceptor list or the manager configuration from its callback.

Parameters
pOwner- unique identity used to remove the interceptor
interceptor- returns true when the assertion is handled
