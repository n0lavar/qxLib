Detailed Description

Counts assertions matching the criteria selected by expected_assert_builder.

Matched assertions are consumed in registration order; other assertions follow normal handling. A matched QX_EXPECT or QX_ENSURE suppresses logging, the assertion callback and debug break; QX_EXPECT control-flow variants still perform their return, break or continue. QX_ENSURE and QX_ASSERT are disabled when QX_WITH_DEBUG_ASSERTS is false. A matched QX_ASSERT or QX_VERIFY also suppresses reporting and debug break, but still calls the fatal exit handler. With the default handler the process terminates without unwinding, so this object's destructor cannot report the count. Otherwise the destructor reports a Google Test failure if the observed count differs from the expected count.
