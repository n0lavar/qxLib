Detailed Description

template<class naming_strategy_t = rtti_naming_strategy_class_name>
class qx::rtti_root< naming_strategy_t >

Polymorphic base for qx class identity and inheritance queries.

Derive an RTTI hierarchy from this type and use QX_RTTI_CLASS in each derived class to supply its identity and extend the inheritance chain. This system does not require compiler RTTI.

Static queries describe the type declaring them; virtual queries describe the object's most-derived registered type. is<T>() checks exact identity, while is_derived_from<T>() also accepts base types.

The naming strategy affects class names, not class identifiers. Names may be empty or shared by several types. The protected destructor prevents deleting an object directly through an rtti_root pointer.
